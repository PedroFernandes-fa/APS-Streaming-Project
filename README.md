# APS-Streaming-Project
Projeto de aplicativo de Streaming para a Diciplina de Analise e Projeto de Sistemas.

---

Neste projeto será implementado os recursos requisitados durante a aula, como os recursos requisitados no dia 22/09:
- Implemente a classe Main para
  - Criar um filme
  - Criar dois episódios
  - Criar uma temporada e adicionar episódios
  - Criar uma série e adicionar a temporada
  - Criar um catálogo
  - Cadastrar o filme e a série
  - Exibir todos os conteúdos
  - Pesquisar conteúdos por uma palavra

- Implemente os testes para SerieTest e TemporadaTest:
  - void deveAdicionarTemporadaNaSerie()
  - void naoDeveAdicionarTemporadasComMesmoNumero()
  - void deveRetornarNullQuandoTemporadaNaoExistir()
  - void deveAdicionarEpisodioNaTemporada()
  - void naoDeveAdicionarEpisodiosComMesmoNumero()
  - void deveRetornarNullQuandoEpisodioNaoExistir()
